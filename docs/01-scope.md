# PoC 범위

## 1. 포함 범위

### 책 입력

- 합성 도서 1권
- 페이지별 텍스트 파일
- 페이지별 삽화 이미지
- 페이지 번호와 파일 경로를 포함한 메타데이터
- 텍스트와 이미지의 페이지 연결

### 원본 데이터 저장

- 책 정보 저장
- 페이지 순서 보존
- 문단 단위 원문 저장
- 페이지별 문단 순서 저장
- 책 전체 문단 순서를 나타내는 sourceOrder 저장
- 이미지 파일 경로와 페이지 연결 저장

### 텍스트 분석

- 등장인물 후보 추출
- 장소 후보 추출
- 물건 후보 추출
- 별칭 후보 추출
- 근거 문단과 페이지 기록
- 동일 개체 후보 통합

### 이미지 분석

- 같은 페이지의 텍스트와 개체 후보를 문맥으로 제공
- 이미지 속 인물 후보 연결
- 외모
- 옷차림
- 표정
- 행동
- 장소
- 실내 또는 실외
- 눈에 보이는 날씨
- 시간대 후보
- 주요 물건
- 이미지에만 나타난 장면 정보

### 멀티모달 병합

- 텍스트에만 있는 정보
- 이미지에만 있는 정보
- 텍스트와 이미지가 함께 지지하는 정보
- 추론된 정보
- 알 수 없는 정보
- 각 정보의 근거와 출처 기록

### 사건과 KG

- 주요 사건 추출
- 사건 참여자 추출
- 인물, 장소, 물건, 사건을 KG 개체로 저장
- 개체 사이의 직접 관계 저장
- 관계의 근거 문단 또는 이미지 기록

### 등장인물 검수

- AI가 고유 등장인물 후보를 모두 제시
- AI가 MAIN, SUPPORTING, MINOR, UNKNOWN 역할을 추천
- 사람이 역할을 확인하고 수정
- 사람이 대화 허용 여부를 설정
- 실제 대화 캐릭터는 1명만 활성화

### 캐릭터 프로필

- 작품의 마지막 사건이 끝난 직후를 기준으로 생성
- 기본 정보
- 역할
- 외모
- 성격
- 가치관
- 목표
- 말투
- 주요 경험
- 다른 인물에 대한 태도
- 작품 종료 시점에 알고 있는 주요 사실
- 근거와 추론 여부

### RAG

- 원문 문단을 검색 가능한 형태로 색인
- 초기 기준선은 문단 검색 후 주변 문단 확장
- 검색 결과에 페이지와 sourceOrder 포함
- 검색 방식은 이후 교체 가능하도록 분리

### 대화

- 최종 캐릭터 프로필 직접 조회
- 사용자 질문과 관련된 원문 RAG 검색
- 사용자 질문과 관련된 KG 관계 조회
- 프로필, 원문, 관계를 외부 LLM에 전달
- 등장인물 관점의 답변 생성
- 발표용 응답에는 참조한 원문과 관계를 포함

### 발표 화면

- 분석된 책 정보
- 등장인물 후보와 검수 결과
- 대화 캐릭터 선택
- 질문 입력
- 캐릭터 답변
- 참조한 원문
- KG 관계
- 최종 캐릭터 프로필

## 2. 제외 범위

- OCR 구현
- 스캔 이미지에서 본문과 삽화를 분리하는 기능
- 장 자동 구분
- 사용자의 장별 대화 시점 선택
- 시점별 관계 변화 관리
- 시점별 캐릭터 지식 획득 추적
- 자동 대화 적합도 점수 계산
- Top 5 대화 캐릭터 자동 선정
- 여러 책 동시 처리
- 회원가입과 로그인
- Spring Security와 JWT를 이용한 인증 및 권한 관리
- Redis와 Prometheus 연동
- Neo4j를 이용한 별도 그래프 저장소
- 결제
- 운영 서비스 수준의 보안 및 배포
- 운영 서비스 수준의 반응형 UI
- 복잡한 관리자 기능
- 자동 승인 없는 완전 무인 분석

## 3. PoC 단순화 가정

- 대화 시점은 결말 직후로 고정한다.
- 테스트 도서는 텍스트와 이미지가 서로 충돌하지 않도록 사람이 검수한다.
- 대화 캐릭터는 작품의 핵심 인물이며 충분한 원문 근거를 가진다.
- 테스트 도서는 핵심 사건의 주요 사실을 대화 캐릭터가 결말까지 알게 되도록 구성한다.
- 서술자만 알고 캐릭터는 모르는 정보가 있다면 사람이 검수 과정에서 캐릭터 지식에서 제외한다.
- 이번 PoC는 완전 자동화가 아니라 AI 분석 후 사람 검수를 포함한다.

## 4. 향후 발전 가능성

- 장과 장면 자동 구분
- 특정 장 시점의 캐릭터와 대화
- 관계와 성격 변화의 시점별 관리
- 캐릭터별 지식 획득 시점 자동 추출
- 대화 적합도 자동 산정
- 여러 청킹 및 검색 전략 비교
- 실제 회사 스캔 시스템 연동
- 여러 책 업로드와 자동 분석
